# Roadmap

Nothing is decided yet. The next project is chosen from the candidates below and from community suggestions.

## Selection criteria

A game can become a project if:

* It can be bought legally today (Steam, GOG, Epic or similar)
* It has a single player mode (no online or anticheat protected games)
* There is a realistic mod path: visual fixes, modern upscaling, RTX Remix, or VR later

## Candidates (no particular order)

* **I.G.I. 2: Covert Strike (2003):** GOG. Visual fixes, RTX Remix test
* **Freedom Fighters (2003):** Steam, GOG, Epic. Visual fixes, RTX Remix
* **Resident Evil 4 (2023):** Steam. DLSS through OptiScaler, VR later
* **Hitman 2: Silent Assassin (2002):** Steam. RTX Remix
* **Project I.G.I. (2000):** only with an original retail disc, since it is not sold digitally

## Suggest a game

Open a [game suggestion](https://github.com/SuspectZero-0/OldGamesReviving/issues/new/choose).
Suggestions that meet the criteria are added to the candidate list.
