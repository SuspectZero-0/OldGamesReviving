## What is in this repository

Only my own work: configuration files, scripts and documentation.
This repository contains **no game files and no third party binaries** (no DLSS, FSR or XeSS libraries, no mod tool executables).
Each game's README links to the official source for everything you need to download yourself.

## How to use a mod

1. Open the game's folder under [games](games/).
2. Read its README completely before changing anything.
3. **Back up your game folder first.**
4. Follow the installation steps in order.
5. If something breaks, follow the uninstall steps or restore your backup.
